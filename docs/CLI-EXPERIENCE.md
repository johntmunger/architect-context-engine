# CLI Experience

## Primary Command

architect chat

## Intended User Flow

1. Detect the target repository.
2. Validate the environment.
3. Crawl the repository.
4. Build project context.
5. Warm the runtime context.
6. Generate the initial response.
7. Write Architect-owned artifacts.
8. Present the response in the IDE when possible.
9. Enter interactive chat mode.
